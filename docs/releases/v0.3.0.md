# KiboTalk v0.3.0

## Web 和 macOS

- 支持所选语言的 macOS 26 及以上设备默认使用 Apple Speech 转写。其他设备仍可使用本地 Sherpaw 模型。
- 实时转写改用 Sherpaw 的流式识别接口。声纹识别会在转写过程中更新说话人标记，历史会话的列表和详情标题对齐。
- 回复建议请求会关闭已知支持关闭的模型的思考模式，以减少等待时间。

## Playground

- 可选实时录制或导入音频文件。文件播放支持暂停、定位、变速和音量调节，Trace 可同步控制播放。
- 会话中可查看实时说话人分轨。设置里可以录制或导入单人音频来录入和替换声纹。

## 下载与试用

- macOS 安装包支持 Apple Silicon 和 macOS 13 及以上，使用临时签名，手动安装和更新。

# KiboTalk v0.2.0

## 首次设置

- Web 和 macOS 共用新版引导。选择对话语言和转写模型，配置回复服务商，通过连接测试后录入声纹。
- 支持搜索服务商和模型，也可以填写自定义 OpenAI 兼容端点。Web 直接请求所选服务，遇到 CORS 限制时可使用 macOS 客户端。
- 语音模型在后台下载，进度显示在右上角。macOS 宽窗口左右分栏，缩窄后上下排列。

## 本地语音与会话

- 转写、语音活动检测和声纹识别在设备上运行。默认 Zipformer 覆盖中、英、日，可按需选择和下载转写模型。
- macOS 安装包内置 Silero VAD 和 CAM++。从旧版升级需要重新录入声纹，本机已有的会话历史可继续查看。
- 历史保留转写和当时的回复建议，标题使用日期和对话语言。

## 下载与试用

- macOS 安装包支持 Apple Silicon 和 macOS 13 及以上，使用临时签名，手动安装和更新。
